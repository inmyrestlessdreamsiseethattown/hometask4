# Лабораторная работа №4

## Вариант 16 — Посадка семян

### Условие задачи

Садовод-робот сажает семена в лунки. Лунка считается "идеальной" для посадки, если все три измеренных параметра кислотности почвы (A, B, C) кратны трем. Запишите условие для "идеальной" лунки.

## Условие

Каждый из трех параметров должен быть кратен трем:

```c
(A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0)
```

## Алгоритм

1. Ввести три целых числа `A`, `B` и `C`.
2. Проверить, делится ли `A` на 3 без остатка.
3. Проверить, делится ли `B` на 3 без остатка.
4. Проверить, делится ли `C` на 3 без остатка.
5. Если все три условия выполняются, вывести сообщение о том, что лунка идеальная для посадки.
6. В противном случае вывести сообщение о том, что лунка не является идеальной.

## Код программы

```c
#include <stdio.h>

int main()
{
    int A, B, C;

    printf("Введите три параметра кислотности A, B и C: ");
    scanf("%d %d %d", &A, &B, &C);

    if ((A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0))
    {
        printf("Лунка идеальная для посадки\n");
    }
    else
    {
        printf("Лунка не является идеальной для посадки\n");
    }

    return 0;
}
```

## Проверка программы

### Пример 1

Входные данные:

```text
6 9 12
```

Все три числа кратны трем.

Результат:

```text
Лунка идеальная для посадки
```

### Пример 2

Входные данные:

```text
6 10 12
```

Число `10` не кратно трем.

Результат:

```text
Лунка не является идеальной для посадки
```
